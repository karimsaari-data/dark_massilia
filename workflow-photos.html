Workflow import photos — Dark Massilia

1Prépare les fichiers

Renomme tes fichiers avec un nom SEO descriptif avant tout

  • marseille-calanques-poulpe-apnee.jpg
  • P1011165.JPG ou 557705461...n.webp

Dépose-les dans le bon dossier New/ :

  • public/images/portfolio/New/photos_sous_marine/Dépollution/
  • public/images/portfolio/New/photos_sous_marine/Biodiversité/
  • public/images/portfolio/New/photos_sous_marine/Caractérisation/
  • public/images/portfolio/New/photos_paysages/Mer/
  • public/images/portfolio/New/photos_paysages/Terre/
  • public/images/portfolio/New/photos_paysages/Horizons/

Formats acceptés : JPG, PNG, TIFF, WebP

2Import

npm run photos:import

Le script fait automatiquement :

  • Slugifie le nom → minuscules, accents supprimés, espaces → tirets
  • Convertit JPG/PNG → WebP 85% (ou copie directe si déjà WebP)
  • Injecte EXIF basique : Artist + Copyright
  • Génère un thumbnail 800w
  • Insère en Supabase (uid auto-incrémenté, visible = false)
  • Archive l'original dans New/done/

3Remplis les métadonnées

npm run dev
  • → Ouvre l'admin → filtre "Incomplet" → remplis titre / alt / lieu / GPS pour chaque photo
  • → Passe visible = true quand c'est prêt
  • → Ctrl+C pour arrêter le serveur

4EXIF détaillé + audit

npm run exif:inject:new && npm run exif:audit:new
  • inject-exif → écrit le titre/keywords dans les EXIF physiques des WebP
  • audit-exif → synchronise la table photos_exif en Supabase

✅ ExifTool inclus dans le projet v13.58
Installé dans scripts/exiftool/ExifTool.exe — aucune installation manuelle requise.

5Build + déploiement

npm run build:photos

→ FTP du dossier dist/ + nouveaux fichiers public/images/

⚠ Points importants

  • Ne jamais ajouter de règle HTTPS dans .htaccess (Cloudflare gère ça)
  • Si des images apparaissent cassées après déploiement → Purge Everything sur Cloudflare
  • Le script de rattrapage pour anciens noms :
    node scripts/rename-legacy-photos.js (dry-run)
    puis --apply
  • ExifTool est dans scripts/exiftool/ et exclu du git (.gitignore). nouveau
    Si absent après un clone : télécharger exiftool.org (Windows 64-bit zip) → extraire → copier dans scripts/exiftool/ExifTool.exe.
