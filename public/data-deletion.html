Instructions pour la suppression de vos données

Conformément au RGPD (Règlement Général sur la Protection des Données), vous avez le droit de demander la suppression de vos données personnelles collectées par notre application Instagram.

Important : Notre application n'enregistre et ne stocke AUCUNE donnée personnelle sur nos serveurs. Toutes les données Instagram affichées sont récupérées en temps réel via l'API Instagram et ne sont pas conservées de manière permanente.

Données collectées par notre application

Notre application accède temporairement aux données suivantes via l'API Instagram :

  • Votre nom d'utilisateur Instagram (public)
  • Votre photo de profil Instagram (publique)
  • Vos publications Instagram (publiques)
  • Nombre d'abonnés (public)

Note : Ces données sont affichées uniquement pendant votre navigation et ne sont pas stockées dans une base de données. Elles proviennent directement d'Instagram via leur API officielle.

Comment supprimer vos données ?

Étant donné que nous ne stockons pas vos données de manière permanente, il n'y a pas de données à supprimer de nos serveurs. Cependant, vous pouvez révoquer l'accès de notre application à votre compte Instagram :

Méthode 1 : Révoquer l'accès via Instagram

  1. Connectez-vous à votre compte Instagram
  2. Allez dans Paramètres et confidentialité
  3. Sélectionnez Site Web et applications
  4. Recherchez "Dark Massilia Website"
  5. Cliquez sur Supprimer ou Révoquer l'accès

Méthode 2 : Révoquer l'accès via Facebook

  1. Connectez-vous à votre compte Facebook
  2. Allez dans Paramètres et confidentialité → Paramètres
  3. Cliquez sur Applications et sites web
  4. Recherchez "Dark Massilia Website" dans la liste
  5. Cliquez sur Supprimer

Méthode 3 : Nous contacter directement

Si vous souhaitez de l'aide ou avez des questions concernant vos données, contactez-nous :

  • Email : karimsaari.com@gmail.com
  • WhatsApp : +33 6 95 33 13 01

Délai de traitement

Si vous nous contactez pour supprimer vos données, nous traiterons votre demande dans un délai de 30 jours maximum, conformément au RGPD.

Tokens d'accès

Les tokens d'accès Instagram utilisés pour afficher votre contenu sont stockés temporairement (durée de vie : 60 jours maximum). Si vous révoquez l'accès via Instagram, ces tokens deviennent immédiatement invalides.

Données de navigation (Cookies)

Notre site n'utilise que des cookies essentiels au fonctionnement de l'application. Pour supprimer les cookies :

  • Effacez l'historique et les données de navigation de votre navigateur
  • Ou utilisez le mode navigation privée/incognito

Vos droits RGPD

En plus du droit à la suppression, vous disposez également des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger vos données inexactes
  • Droit d'opposition : vous opposer au traitement de vos données
  • Droit à la portabilité : recevoir vos données dans un format structuré
  • Droit de retirer votre consentement : à tout moment
