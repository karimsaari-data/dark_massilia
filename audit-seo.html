Mission 01Audit Technique — Navigation & Crawlabilité
✅
CONFORME — Aucun blocage de crawl détecté

La navigation utilise <Link to="..."> de React Router, qui génère des balises <a href> standards dans le DOM. Le SSR prerender garantit la livraison de HTML statique à Googlebot.

⚠️
Point d'attention — Redirections legacy

Les routes /missions, /medias, /photos, /reseaux, /twitter, /arte, /sources, /carte, /local-guide sont redirigées côté client via <Navigate replace>. Si Googlebot indexait ces URLs sans exécuter JS, il ne verrait pas le redirect. Vérifier que le .htaccess du serveur Apache contient les 301 côté serveur correspondants.

Mission 03Diagnostic de Désalignement

Pages à refonte profonde (3 pages)

Ces pages sont actuellement hors-sujet par rapport au positionnement Méditerranée / Apnée / Dépollution ou présentent des problèmes structurels bloquants.

🔴 Refonte urgente
/communaute
Page Communauté sans H1
La page agrège des stats de réseaux sociaux (Instagram 24k, TikTok 21k, Facebook 64k) dans une logique de "preuve sociale". Aucune requête transactionnelle ne cible "communauté environnementale marseille". Le H1 est totalement absent — erreur critique pour le signal sémantique. À transformer en landing "Rejoindre le mouvement / Bénévolat" ancrée sur le Silo 2.
🟡 Hors scope
/local-guide-marseille
Google Local Guide — Orthogonal aux silos
Page entièrement dédiée au statut "Local Guide Niveau 10". Positionnement orthogonal aux deux silos : ni photographie artistique, ni dépollution. H1 générique ("Google Local Guides" — 3 mots). Peut fonctionner comme page E-E-A-T de crédibilité, mais doit recevoir un noindex ou être recentrée sur la valeur documentaire pour la Méditerranée.
🔴 Thin content + H1 absent
/carte-calanques
Carte Interactive — Page sans H1 et contenu indexable insuffisant
Page techniquement bien structurée (iframe Google My Maps + contenu éditorial) mais sans H1 — erreur critique. Le title est bon, mais le contenu indexable se résume à une légende de carte et des liens externes. Google perçoit une page de "thin content". Nécessite un H1 explicite + un bloc éditorial enrichi (contexte des sites de dépollution, biodiversité observée) pour exister pleinement dans le Silo 2.

Anomalies de structure à corriger sans attendre (3 points)

  • ⚡
    H1 sous-optimisé — /sauver-marseille-documentaire-arte

    H1 actuel = "Documentaire ARTE" (2 mots). Perd tout le potentiel de la requête navigationnelle "Sauver Marseille ARTE pollution". Le titre de la page est excellent, mais le H1 doit reprendre les mots-clés cibles : ex. "Pollution : il faut sauver Marseille ! — Documentaire ARTE avec Karim Saari".

  • 🔒
    noindex non documenté — /actualites

    La page est intentionnellement en noindex: true dans seo.js (flux X/Twitter = thin content dynamique). Correct techniquement, mais ce paramètre doit être commenté explicitement dans le code pour ne pas être supprimé par erreur lors d'une future refonte.

  • 📄
    Pages légales sans noindex explicite — /mentions-legales & /confidentialite

    Ces pages utilisent le DEFAULT_SEO fallback (title et description génériques de l'accueil). Elles doivent être déclarées dans SEO_PAGES avec noindex: true, nofollow: true pour éviter toute indexation parasite et dilution du budget de crawl.
